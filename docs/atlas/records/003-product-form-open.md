# 产品形态未定：陪伴与规划如何融合、陪伴形象是什么、主界面长什么样

策略讨论把陪伴和规划定为融合方向，但具体形态没有定：陪伴形象是什么、主界面是什么、陪伴与规划在界面上怎么分工。信息采集模块的设计明确与形态讨论解耦，形态怎么定都需要那一层。

判断依据：评委看重「一个真实的校园时刻，一个让人『它懂我』的交互瞬间，形态干净、审美过关」。
