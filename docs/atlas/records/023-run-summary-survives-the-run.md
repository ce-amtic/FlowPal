# 进行中那一行在跑完之后留下，消失的只是加载动画

一次投放跑动时，回复上方有一行说它此刻在动哪一个对象（「正在更新「组会 PPT」」）。
跑完之后这一行**不清掉**，只是换成完成态的说法、并去掉加载动画；多于一步时那个
展开器照旧能打开看全部。

这是 [[017-agent-output-is-receipt]] 的延伸而不是例外。回执要能被指认：模型说的那
段话是结论，「动过哪些对象」是它的凭据。把凭据随加载态一起清掉，用户就只剩一段无从
核对的话——而这个 agent 的边界本来就建立在「每句话有可指出的凭据」上
（[[018-agent-boundary-is-initiative]]）。

仍然不播步骤。留下的是对象，不是「第 3 步 / 共 5 步」，也不是耗时统计——清点属于
[[019-copy-unloads-never-tallies]] 禁止的那一类。一步都没有时这一行整个不出现：
没有对象可指，一行空壳比没有更差。
