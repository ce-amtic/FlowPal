# 形象与界面风格是否搭配，以及它在桌面上如何不突兀

形态定了，形象的**视觉**没定：团队已有一版形象素材，尚未进仓库。两件事因此悬着：

1. 该形象与主窗口的设计系统（暖低饱和强调色、极轻卡片、毛玻璃底、无描边）是否搭配。初步判断是极简风格比较百搭，但要素材进仓库后实看。
2. 它待在桌面上如何不显得突兀。已记为规格待验：极淡或无投影、贴边时降低不透明度、鼠标靠近才完全实体化、不盖在全屏应用之上、形状之外鼠标穿透。这些是必要条件，不一定充分——真正的问题可能是形象与桌面其余元素的风格关系，而不是窗口属性。

这一条是 [[003-product-form-open]] 中"陪伴形象是什么"的剩余部分：形态与职责已由 [[009-companion-capability-subset]] 定下，视觉未定。
