# 回复标记的渲染分支由类型系统保证穷尽

标记的元素表 `MARKUP_ELEMENTS` 现在是 `as const satisfies`，由它导出 `MarkupTag`
联合类型；渲染端的分支表写成 `Record<MarkupTag, …>`。表里加了标签却没写渲染分支，
`pnpm typecheck` 直接不过。

之所以交给类型而不是运行时断言：漏一个标签的症状是提示词教会了模型一个应用不会画的
标签，那一行悄悄退化成纯文字，没有任何地方报错，肉眼要到演示当天才发现。运行时断言
只能在跑到那一行时才响，而这套东西恰恰要求它在写代码时就响。检查脚本里另有一条对照：
表里每个标签的示例必须真的解析成它自己——示例是模型唯一照着抄的东西。

代价是元素表加标签不再是单点改动，必须连着渲染分支一起落；这正是想要的耦合。
