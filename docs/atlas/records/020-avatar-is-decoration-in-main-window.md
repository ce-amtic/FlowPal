# 形象在主窗口是装饰，不承担任何功能入口

主窗口里的形象只是一块会眨眼、会跟着光标看人的装饰。表情固定，不随系统状态变，
也不是任何操作的入口。

判据可执行：**把它整块删掉，应用的每个动作仍然做得到。** 反过来，如果哪天出现
「要记录得先点它一下」，那就是 Microsoft Bob。这是 [[009-companion-capability-subset]]
里「能力是子集」在主窗口这一侧的具体形态——分量相等讲的是能力，不是这一处动不动。

备选是让它承担状态投影（正在理解 / 落库成功 / 深夜各换表情）。没选，因为那些状态
在别处已经说清楚了（记录框自己会说「正在理解」），再用表情说一遍是同一件事说两遍，
而一旦用户开始依赖表情读状态，删掉它就有代价了。

代价是一个常驻 WebGL 上下文换零功能。接受，因为「在桌面上不突兀」本身是这个产品的
要求：完全不动的形象像贴纸，眨眼与跟随视线是那点温度的来源。窗口不可见时 rAF 停。
