# 原始碎片不可变永不删除，条目派生可改，每个字段带原文引用

用户扔进来的原始碎片（Fragment）永久保留原文，不删除、不修改。LLM 理解后的条目（Item）是派生结果：用户可以改字段、合并、丢弃，但改动记录保留。每个结构化字段都带引用，指向原文的哪一段。

替代方案是只存解析结果、丢掉原始输入。被否决的原因：「扔了就可以忘」只有在用户随时能看到「它是从哪句话理解出来的」并一键修正时才成立；丢了原文，错误的理解就无法追溯，也无法在去重合并、改期检测时回到来源。

来源：docs/信息采集模块-设计文档.md §1 原则 5「来源可追溯」、§5 数据模型（「Fragment 永不删除，Item 可以被用户改、合并、丢弃，但改动记录保留」）。用户在 bootstrap 访谈中确认。
