# LLM 回应语气：在场而不评判，说中具体细节，不责备不催不谈意志力

所有面向用户的 LLM 输出遵守三条语气约束：在场而不评判；回应要说中用户处境里的具体细节，不做泛泛安慰；不责备、不催、不用「意志力 / 自控力耗竭」叙事。

被否决的替代方案是题面字面上的「外部监督感」。自我决定理论与心理抗拒理论表明被监控会削弱自主性并触发反抗；陪伴与监督的差别在于对方是否评价你。Wohl et al. 2010 显示为上一次拖延原谅自己的人下一次拖延更少，所以带责备的语气是在制造下一次拖延。自我损耗理论大规模复现失败，不作为叙事基础。被理解感的关键在具体性（Reis 的 perceived partner responsiveness）。

这条约束没有任何机制强制，写进 PROJECT.md 的 Working rules。
