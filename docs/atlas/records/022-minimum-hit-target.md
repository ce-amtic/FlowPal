# 可操作的元素都有最小命中面积，动作不做成裸文字链接

界面上每一个可点的东西，命中区不小于 `--target-min`：桌面 32px，`pointer: coarse`
下 44px。视觉大小不必跟着变——靠内边距把命中区撑开，必要时用负外边距把撑出来的
部分收回去，排版不动。

两条一起成立才算数：

1. **动作是按钮，不是一段带 hover 的文字。**「更小的一步」「换一件」「清空」这些
   原本是 `padding: 0` 的裸文字，既难点中，也读不出它可操作。次要动作仍然轻，但
   要有按钮的形状（内边距、悬停的一层浅底、pill 圆角）。导航才用 `Link`。
2. **键盘要看得见焦点。**`:focus-visible` 的焦点圈用 `--accent-line`，走 `outline`
   与 `outline-offset`，不用 box-shadow 模拟。

触摸那一档不是为了将来：手机端是局域网直连同一个界面，不另做一套
（[[006-local-first-no-remote-backend]]），所以同一份样式必须在手指下也成立。
